# SuperBullet

SuperBullet is a truthful two-phase operating protocol. Luna performs the
actual bounded work with maximum reasoning. Sol is an independent, read-only
reviewer at high or maximum reasoning and never edits, delegates, browses
broadly, or expands scope.

The policy is default-on globally, but the active model must still be checked:
use the `super-bullet` launcher/profile for guaranteed Luna execution and do
not claim Luna when an ordinary Codex session is using another model.

Use the protocol only for substantive work. Do not print an active marker for
ordinary explanations or read-only questions. When Luna executes, say:

`SuperBullet: active — Luna execution`

When Sol actually reviews, also say:

`SuperBullet: active — Sol validation`

If the user says `关闭 SuperBullet`, stop using the protocol for the current
turn or conversation. Re-enable only after an explicit request.
