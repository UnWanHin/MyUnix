# MyUnix migration graph

Open the `MyUnix` repository as an Obsidian vault, then open **Graph view**.
This folder contains only portable Markdown and `[[wiki links]]`; the graph
updates whenever the tracked notes change. Obsidian's local layout, plugins and
personal preferences are kept in `.obsidian/`, which this repository ignores.

Start with [[workstation]].

## Scope

- Public, reproducible Fedora workstation configuration only.
- No credentials, chat data, browser state, SSH keys, phone pairing data or
  device-specific DMS state.
- No localhost documentation server is required.

## Navigation

- [[workstation]] — operating-system and desktop relationship hub.
- [[installation-map]] — visual guide to one-click, custom and on-demand modules.
- [[modules]] — module ownership and source manifests.
- [[session]] — GNOME/Niri/DMS/Fcitx session boundaries.
- [[recovery]] — export, restore and diagnosis commands.
